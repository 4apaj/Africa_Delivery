# SLO-контракт: Каталог (поиск и просмотр)

| Поле | Значение |
|-|-|
| Сервис | Модуль `catalog` монолита (ADR-001) с CDN и офлайн-кешем (ADR-002) |
| Пользовательский путь | UC2 «Поиск и просмотр каталога» |
| Владелец | Команда ядра. Дежурный - по ротации |
| Потребители | Покупатели (приложение), маркетинг (диплинки из рекламы, A2) |
| Окно | 30 дней скользящее |
| Источник требований | NFR-02, NFR-08, NFR-09, NFR-11, A2 «< 2 секунд до первого товара» |

## SLI: что и как измеряется

| SLI | Хороший событие / все события | Источник данных |
|-|-|-|
| **Доступность на edge** | Ответы CDN на `GET /v1/catalog/*` со статусом < 500, включая отдачу stale при ошибке origin / все запросы | Логи CDN → Loki → Prometheus recording rule |
| **Доступность origin** | `http_server_requests_total{module="catalog",code!~"5.."}` / все | Prometheus (OTel) |
| **Задержка origin** | Запросы с `http_server_duration_seconds` <= 0,3 с / все (p95). Отдельно p99 <= 0,8 с | Prometheus histogram |
| **Время до первого товара** (RUM) | Сессии, где первая карточка отрисована <= 2 с / все сессии на 3G | OTel mobile SDK → Collector |
| **Свежесть цены** | Карточки, у которых цена в кеше отличается от БД не дольше 60 с / все изменения цены | Синтетическая проверка раз в минуту |

## SLO: целевые значения

| SLO | Цель | Бюджет ошибок за 30 дней |
|-|-|-|
| Доступность на edge | **99,95 %** | 21,6 мин или 0,05 % запросов |
| Доступность origin | 99,9 % | 43,2 мин |
| Задержка origin p95 / p99 | 95 % <= 300 мс / 99 % <= 800 мс | 5 % / 1 % медленных запросов |
| Время до первого товара p75 | 75 % сессий <= 2 с | - |
| Свежесть цены | 99 % изменений видны <= 60 с | 1 % |

Цена на карточке - витринная. Цену, которую платит покупатель, всегда перепроверяет модуль заказа при оформлении (ADR-002). Поэтому устаревшая витрина не приводит к ошибке в деньгах.

## SLA: что гарантируется и что происходит при нарушении

| Кому | Что гарантируется | При нарушении |
|-|-|-|
| Бизнесу (CEO, маркетинг) | Каталог и диплинки из рекламы открываются в 99,95 % случаев; в окно кампании 15-31.10 - без плановых работ | Постмортем <= 3 рабочих дней. Исчерпан бюджет - релизы фич каталога заморожены до восстановления |
| Продавцам | Новая или изменённая карточка видна покупателям <= 5 мин после модерации | Компенсации не предусмотрены (бесплатная площадка на пилоте). Публичный статус-канал в WhatsApp |
| Внешнего SLA с денежной ответственностью | Нет. Партнёрам и покупателям не продаётся | - |

**Политика бюджета ошибок:** сожжено >= 50 % за 7 дней - следующий спринт на надёжность. Сожжено 100 % - заморозка фич, исключение только для исправлений.

## Исключения и зависимости

Не считаются нарушением: плановые работы, объявленные за 48 часов вне 18:00-23:00 местного времени, и отсутствие сети у клиента (офлайн-режим считается успехом, если отдал кеш). Зависимости: PostgreSQL ячейки, Valkey (кеш), CDN. Отказ кеша не должен нарушать SLO - Cache-Aside с fallback на БД ([fmea](../fmea.md), FM-07).

## OpenSLO

```yaml
apiVersion: openslo/v1
kind: SLO
metadata:
  name: catalog-edge-availability
  displayName: Каталог - доступность на edge
spec:
  service: catalog
  budgetingMethod: Occurrences
  timeWindow:
    - duration: 30d
      isRolling: true
  indicator:
    metadata:
      name: catalog-edge-good-ratio
    spec:
      ratioMetric:
        counter: true
        good:
          metricSource:
            type: Prometheus
            spec:
              query: sum(rate(cdn_requests_total{path=~"/v1/catalog/.*",status!~"5.."}[5m]))
        total:
          metricSource:
            type: Prometheus
            spec:
              query: sum(rate(cdn_requests_total{path=~"/v1/catalog/.*"}[5m]))
  objectives:
    - displayName: edge-availability
      target: 0.9995
```

## Assumptions

- Цели действуют для Года 1; при GMV >= $37 млн пересматриваются по ступеням [availability-strategy.md](../availability-strategy.md).
- Доля запросов каталога через edge >= 90 % обеспечена кешированием ADR-002; до включения CDN статистика origin калибрует базовые линии.
- «Сессия на 3G» определяется по телеметрии OTel mobile SDK (тип сети, модель устройства), а не по самоотчёту.
