## Реестр ADR

Все ADR оформляются по единому шаблону [adr-template.md](adr-template.md), нумерация сквозная. Каждое решение ссылается на противоречие C-xx из [Task1/contradictions.md](Task1/contradictions.md).

| ADR | Решение | Статус | Противоречия |
|-|-|-|-|
| [ADR-001](Task2/adr-001-architecture-style.md) | Модульный монолит на Go, сервисы по триггерам | Предложено | C-01, C-02, C-03, C-04, C-10, C-12 |
| [ADR-002](Task3/adr-002-caching-strategy.md) | Стратегия кеширования: 4 уровня, деньги не кешируются | Предложено | C-01, C-02, C-07, C-10, C-12 |
| [ADR-003](Task4/adr-003-data-residency.md) | Резидентность данных: страновые ячейки у локальных провайдеров, глобальный слой без ПДн, обратимость конфигурацией | Принято условно (до заключения юриста) | C-07, C-08, C-03 |
| [ADR-004](Task5/adr-004-payment-provider.md) | Платёжный провайдер: M-Pesa Daraja напрямую + 2 PSP на страну + тонкий свой оркестратор, all-in ≈ 1,5 % GMV | Предложено | C-04, C-05, C-06, C-09, C-11 |
